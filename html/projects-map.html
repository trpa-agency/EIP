The map shows every EIP project with a known location. Focus Areas are derived from the EIP # prefix and match LakeTahoeInfo's four official categories.

Some projects are basin-wide — research, monitoring, planning, or other work without a single specific point on the map. Those don't appear as pins but are included in the CSV export with empty lat/lon so you have the complete EIP record list.

Click any pin or list row to view the project on LakeTahoeInfo.

Snapshot data refreshed nightly via GitHub Actions.
